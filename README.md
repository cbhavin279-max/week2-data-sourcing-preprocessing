# NCRB Crime Data Analytics for E-Governance

## Project Overview

This project focuses on analyzing crime statistics from the
National Crime Records Bureau (NCRB), India, using Python
and data analytics techniques.

The main objective is to explore crime patterns, perform
statistical analysis, create data visualizations, and design
a dashboard that supports data-driven decision-making
in e-governance and public safety management.

This project was developed as part of a Data Analytics
and E-Governance internship.

## Project Objectives

- Analyze NCRB crime statistics.
- Perform data cleaning and preprocessing.
- Identify missing values and duplicate records.
- Conduct descriptive statistical analysis.
- Calculate mean, median, and standard deviation.
- Explore correlations between numerical variables.
- Create charts and graphical visualizations.
- Propose predictive modeling using linear regression.
- Design an e-governance analytics dashboard.
- Generate reports using Python.
- Provide recommendations for public safety planning.

The proposed dashboard includes:

2. Distribution of reported crimes across states.

## Installation

### Step 1: Install Python

Download Python from:

https://www.python.org/

### Step 2: Install Required Libraries

Open the terminal and run:

pip install pandas numpy matplotlib seaborn scikit-learn python-docx

### Step 3: Download the Project

Clone the GitHub repository:

git clone https://github.com/YOUR-USERNAME/NCRB-E-Governance-Analytics.git

Replace YOUR-USERNAME with your GitHub username.

### Step 4: Run the Project

Open the project folder in Visual Studio Code.

Update the dataset file path in the Python script.

Run:

python REPORT.PY

- Missing values may affect statistical analysis.
